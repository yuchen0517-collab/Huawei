## 5. 素材规范与目录

### 5.1 规格

| 项 | 标准 |
|---|---|
| 分辨率 | 1920×1080（与录制窗口一致） |
| 帧率 | 30fps |
| 容器 / 编码 | MP4 / H.264，`yuv420p` |
| 音频 | 第 7 天主片不录人声时保留静音轨；后期旁白另轨 |
| 字幕 | SRT，UTF-8，单行 ≤ 20 字，底部安全区 |
| 命名 | `srt/<段号>_<镜头名>.srt`，如 `srt/09_autoplay.srt` |

### 5.2 目录结构

```
recording-day7/
├─ raw/                 # 完整原片：full_YYYYMMDD.mp4、未剪辑的连续录制
├─ segments/            # 9 段无字幕原片：01_overview.mp4 … 09_autoplay.mp4
├─ srt/                 # 9 份字幕：01_overview.srt … 09_autoplay.srt
├─ cover/               # 封面帧：cover_1920x1080.png
└─ final/               # 烧字幕成片、合并版：day7_full_subtitled.mp4
```

**保留要求**：
- `raw/` 完整原片不删；
- `segments/` 保留**无字幕原片**；
- `final/` 只放烧字幕/合并版，不覆盖原片；
- 每段文件名与上表一致，便于任何人重导。

### 5.3 重导命令（任何成员可执行）

```bash
# 合并 9 段（无字幕）
printf "file '%s'\n" segments/*.mp4 > segments/list.txt
ffmpeg -f concat -safe 0 -i segments/list.txt -c copy final/day7_full.mp4

# 烧录单段字幕
ffmpeg -i segments/09_autoplay.mp4 -vf "subtitles=srt/09_autoplay.srt" \
  -c:v libx264 -pix_fmt yuv420p -r 30 final/09_autoplay_subtitled.mp4
```

## 6. 应急预案

| 场景 | 处置 | 禁止 |
|---|---|---|
| 随机议题生成失败 | 当前构建无随机议题入口，不录主片；若后续接入，切**同输入**预录片段 | 用不同输入冒充；把生成失败剪成成功 |
| 模型等待过长 | 剪掉等待空白，保留同一会话前后；必要时整段重录 | 拼接不同会话；用加速伪造响应 |
| 自动推演版本不一致 | 系统会 `stopAutoPlayFor('version_conflict')`，日志红色「版本不一致」；**重录该段**，不手动改 state | 手动改 `state.version` / 重试掩盖 |
| `ROUND_LOCKED` 注入后 | 自动停止并记红字原因；重录时先复位场景再注入 | 反复点开始造成无限重试 |
| 录屏中断 / 文件损坏 | 从 `raw/` 重剪对应段；`segments/` 可单独重录 | 删除 `raw/` 原片 |
| 任何成员接手 | 按第 2 节清单 + 第 5.3 节命令重导；文件名与目录不变 | 改文件名、改目录层级 |
| 密钥 / 私有配置 | 录制前确认 `httpBase` 为空（mock）；控制台无 token / 内网 IP；`.env`、`*.local` 不入镜；书签/历史不出现 | 在镜头内打开 `.env`、网络面板、控制台历史 |
| 控制台报错 | 停止录制，定位后重录该段 | 用后期遮罩盖住红色报错 |
