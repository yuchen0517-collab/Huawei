## 1. 基础参数

| 项 | 规范 |
|---|---|
| 分辨率 | 1920×1080 |
| 帧率 | 30fps |
| 容器/编码 | MP4 / H.264 / `yuv420p` |

## 2. 字体与字号

| 用途 | 字体 | 字号 | 颜色 |
|---|---|---|---|
| 主标题（封面/片头） | Georgia / Times New Roman / 宋体（衬线） | 88–96px | `#c9a227` |
| 副标题 | Microsoft YaHei / PingFang SC（无衬线） | 34–38px | `#ede6d6` |
| 正文说明 | Microsoft YaHei / PingFang SC | 26–30px | `#ede6d6` |
| 字幕 | Microsoft YaHei / PingFang SC | 40–44px | `#ede6d6`，描边/底色可选 |
| 页脚/来源 | Microsoft YaHei / PingFang SC | 22–24px | `#a99a84` |

- 不使用外部字体、CDN、图标库；只用系统字体。
- 衬线只用于大标题；正文与字幕一律无衬线。

## 3. 配色

| Token | 值 | 用途 |
|---|---|---|
| 背景 | `#0d0c0a` | 封面/片头/收尾底 |
| 主金 | `#c9a227` | 标题、细线、强调 |
| 米白 | `#ede6d6` | 正文、字幕 |
| 辅助灰 | `#a99a84` | 页脚、次级信息 |

- 不引入第二金色、渐变卡片、圆角玻璃拟态。

---

## 4. 安全区

| 区域 | 规范 |
|---|---|
| 左右 | 各 8%（154px）内不放关键文字 |
| 底部 | 10%（108px）为字幕安全区；字幕不进入最底部 80px |
| 顶部 | 8%（86px）；不遮三处版本徽标 |
| 错误横幅 | 字幕与封面元素不得遮挡 `#errorSlot` |
| 数据来源声明 | `08_finale` 页脚声明帧不得裁切、不得被字幕遮挡 |

## 6. 片头 / 片尾（可选）

- 片头/片尾各 ≤3s；插入后总时长仍须 205–215s。
- 只用硬切或静态卡，不加转场、粒子、闪白。
- 片尾必须保留数据来源声明帧，不得用黑场直接覆盖。

## 7. 自检

1. 1920×1080 / 30fps / MP4。
2. 字幕不遮版本徽标、错误横幅、数据来源声明。
3. 封面/字幕无外部字体与网络资源。
4. 无分数/胜率/效率数字。
5. 片头片尾不改变 03:30 ±10s。
