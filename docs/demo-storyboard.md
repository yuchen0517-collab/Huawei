## 5. 录制禁令

1. **不编造数字**：任何“效率提升 X%”“胜率 Y%”都不出现；没有真实统计就不报收益。首轮 `speaker_score` 为 `null` 时只显示“首轮不计分”，不得填 0 或补一个分数。
2. **不把模型内容当事实**：左栏解说必须带“模型生成 · 仅供参考”，镜头不得裁掉该行。
3. **不暴露对方底牌**：右栏对方态势只许出现估计值与可信度；不得口述“对方其实……”这类真值。
4. **不录未实现功能**：多边、议题知识图谱、关系矩阵一律不出镜，包括鼠标悬停误触。
5. **不快速连点**：所有点击停留 ≥1s，确保评审能看清状态迁移。
6. **不遮挡版本号**：任何鼠标轨迹不得压住顶栏版本徽标与报价板底部版本位。
