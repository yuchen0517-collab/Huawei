# 事实卡采集规范（算力 / 芯片出口管制议题）

> 给组员看的一份操作手册。目标不是"找资料"，是**找到能被 agent 直接引用的事实**。

---

## 一、先明确这张卡是干什么的

我们不是写报告，是在给两个 AI 角色**准备台词素材**。

每一条卡最终会进到 agent 的系统提示里，变成它说话的依据：

```
## 可引用的事实（只能引用这里的数据）
- 【行动】2025-05 美国 BIS 撤销 AI 扩散规则，改为逐案许可（BIS 公告）
- 【数据】中国智能算力规模突破 2500 EFLOPS，同比增长 146%（中国经营报 2026）
```

所以判断一条资料好不好，只问一句：

> **这句话能不能被 agent 原样说出口，并且经得起追问？**

---

## 二、三条硬标准（不满足就别交）

| 标准 | 意思 | 不合格的样子 |
|---|---|---|
| **可溯源** | 有一手来源，附链接和日期 | "据说""有报道称""业内普遍认为" |
| **可验证** | 数字能被第二个来源印证；只有单一来源的估值要标"估计" | "约 1000 亿"（谁的统计？哪一年？） |
| **有时效** | 2024 年以后优先；政策必须写生效/发布月份 | 2021 年的占比当作现状用 |

---

## 三、五类素材，按价值排序

### A 类：官方立场原文（最重要）

一方公开说过的红线、承诺、条件。**这是 agent 的"底线"从哪来的依据。**

找什么：
- 政府白皮书、官方声明、外交部/商务部/国务院新闻办表态
- 多边场合发言稿（联合国、世界互联网大会、G20）
- 双边联合声明、公报

### B 类：已采取的实际行动（政策工具）

不是"主张"，是**真的做了**。这类最有说服力，因为它可核查。

美国方向找：BIS 出口管制规则（EAR 修订）、实体清单增补、AI 芯片对华销售限制、CHIPS 法案补贴、对外投资审查
中国方向找：算力基础设施政策（东数西算、智算中心）、生成式 AI 管理办法、关键矿产（稀土/镓/锗）出口管制反制、数据出境安全评估

### C 类：硬数据（数字）

谈判里最能压人的东西。要求：**指标名 + 数值 + 年份 + 统计机构**。

美国方向：全球 AI 算力占比、AI 芯片市场份额、数据中心投资额、前沿模型数量
中国方向：智能算力规模（EFLOPS）、算力增速、智算中心/万卡集群数量、AI 核心产业规模

### D 类：关键人物原话（引用）

一句官员或谈判代表的原话，比一段转述有力。要有**人 + 职务 + 时间**。

### E 类：智库/学术评估（背景，不能当事实引用）

用来理解"对方为什么这么想"，标注为"评估"或"观点"。

---

## 四、数量与配比（这条最容易被忽略）

**每国 12–15 条进 Prompt，但要收集 20–25 条供筛选。**

| 类型 | 目标条数 | 作用 |
|---|---|---|
| A 红线/立场 | 3–4 | 定底线 |
| B 实际行动 | 5–6 | 讲"我们做了什么" |
| C 数字 | 4–5 | 举证 |
| D 原话 | 2 | 增强可信度 |
| E 智库 | 2 | 备用，一般不进 Prompt |

### ⚠️ 必须保证双方"对称"

如果美国有 6 条行动、中国只有 2 条，agent 打起来会一边倒——一方满口具体措施，另一方只能说空话。**这不公平，演示效果也差。**

自查方法：把两边的条数并排看，**行动数、数字数不要差超过 2 条**。

---

## 五、好例子 vs 坏例子（照着写）

### ✅ 好

> **【行动】** 2025-05 美国商务部 BIS 撤销 AI 扩散规则（AI Diffusion Rule），改为逐案许可，并发布"高概率执法"通告。
> 时间：2025-05｜来源：BIS 公告 / Kirkland & Ellis 分析｜可信度：A

为什么好：主体明确、有动作、有月份、可点开原文。

> **【数字】** 中国智能算力规模突破 2500 EFLOPS，同比增长 146%。
> 时间：2026｜来源：中国经营报｜可信度：B（需二次核实原始统计口径）

为什么好：指标 + 数值 + 增速 + 出处，还标了"待核实"。

### ❌ 坏

| 写法 | 问题 |
|---|---|
| 美国限制中国芯片 | 没有时间、没有具体措施，agent 说出来像废话 |
| 中国算力很强 | 没有数字，无法举证 |
| 据说美国占全球算力 70% | 无来源，一问就露馅 |
| 中国将在 2030 年超越美国 | 预测当事实，会被评委抓 |
| 大量资料显示…… | "资料"是什么？不能引用 |

## 六、禁区（会导致现场翻车）

1. **二手转述当一手**："某媒体报道称""有分析指出"——要么找到原始出处，要么丢掉
2. **无出处的整数**：所有数字必须有统计机构名
3. **预测当事实**："预计""有望""将"，一律标为"评估"类
4. **旧数据不标年份**：2021 年的占比，今天用就是错的
5. **把观点当数据**："中国威胁论""美国霸权"这类判断，不能进事实卡
6. **来源不可点开**：链接打不开 = 无法核验 = 作废

---

## 七、交付格式

用 `事实卡模板.xlsx`，三个 sheet：

- `中国_事实卡`
- `美国_事实卡`

字段说明：

| 字段 | 要求 |
|---|---|
| 编号 | CN-01 / US-01，按类型分组 |
| 类型 | 立场 / 行动 / 数字 / 引用 / 智库（下拉选） |
| 内容 | **一句话，≤60 字**，能被 agent 直接说出口 |
| 数值 | 仅数字类填，如 `2500 EFLOPS`、`+146%` |
| 时间 | `2025-05` 格式，政策类必填 |
| 来源名称 | 机构或媒体名 |
| 来源链接 | 必须是能直接看到原文的链接 |
| 可信度 | A 官方一手 / B 权威媒体 / C 待核实 |
| 备注 | 口径说明、存疑点、可替代来源 |

**一句话原则**：一条卡只说一件事。想写"美国管制芯片并补贴本土"就拆成两条。

---

## 八、我这边怎么验收

收到后我会自动跑一遍：

1. 链接是否可达
2. 数字是否能在来源正文中找到
3. 同一指标是否有冲突来源
4. 双方条数是否对称
5. 单条字数是否超限（超 60 字会被压缩，丢信息）

不合格的会退回并说明原因。**通过了才会进 Prompt**——因为写进去的东西，agent 会当成真理说出来。

---

## 九、分工建议

两个人并行，各负责一国，**同一天开始、同一天交**（否则一边齐一边不齐，对称性没法把控）。

预计：**每人半天到一天**。宁可少而准，不要多而虚——12 条真实可引用的，胜过 50 条含糊的。
