## 二、双方三指数更新规则

> v1.1 起同时维护双方三指数：`indexes_update` 记己方，`player_indexes_update` 记对方。

### 2.1 主体利益值（Interest Index）
- **范围**：0-100，己方初始值 {initial_interest}，对方初始值由场景配置决定
- **含义**：一方核心利益被满足的程度
- **更新逻辑**（以"本轮发言造成的影响"计）：
  - 对方做出有利于我方的让步 → +3 到 +8
  - 对方接受我方核心诉求 → +5 到 +10
  - 对方提出对我不利的方案 → -3 到 -8
  - 对方触及我方核心利益底线 → -8 到 -10
  - 纯程序性发言/寒暄 → ±0 到 ±1
- **约束**：累计不超过100，不低于0

### 2.2 国际形象值（Image Index）
- **范围**：0-100，初始值 {initial_image}
- **含义**：一方在国际社会中的声誉与形象
- **更新逻辑**：
  - 展现建设性态度、提出共赢方案 → +2 到 +5
  - 使用合理论据、援引国际规则 → +1 到 +3
  - 强硬表态、发出威胁 → -2 到 -5
  - 出尔反尔、前后矛盾 → -5 到 -8
  - 人身攻击、情绪化表达 → -5 到 -10
- **约束**：累计不超过100，不低于0

### 2.3 盟友信任度（Trust Index）
- **范围**：0-100，初始值 {initial_trust}
- **含义**：盟友和潜在合作伙伴对一方的信任
- **更新逻辑**：
  - 维护盟友利益、为盟友发声 → +3 到 +6
  - 信守承诺、履行已达成的共识 → +2 到 +4
  - 出卖盟友利益、单方面妥协 → -5 到 -10
  - 立场模糊、态度摇摆 → -2 到 -4
- **约束**：累计不超过100，不低于0

### 2.4 delta 取值参考

> 说明：下表是"这句话对说话方自身"的影响；对对方的影响只作用于 Interest（由条款效用差计算）（`player_indexes_update`）
> Image 与 Trust 仅作用于发言方自身，不做反向。

| 发言类型 | interest_delta | image_delta | trust_delta |
|---------|---------------|-------------|-------------|
| 提出共赢方案，兼顾双方 | +2~+4 | +3~+5 | +1~+2 |
| 强硬坚持核心立场 | +1~+2 | -1~-3 | +2~+4 |
| 有条件让步，换取利益 | -2~-4 | +1~+2 | 0~+1 |
| 程序性推进，无实质变化 | 0~+1 | 0~+1 | 0~+1 |
| 触及对方红线，引发对抗 | +2~+3 | -3~-5 | -1~-2 |
| 妥协退让，损害己方利益 | -4~-8 | -2~-3 | -3~-5 |
| 情绪化、指责对方 | 0~-1 | -5~-8 | -2~-4 |
| 巧妙运用外交辞令化解矛盾 | +1~+2 | +3~+5 | +1~+3 |
